# Workflow examples for v4

These prompts are reference examples for a requested task, not automatic actions. Verify the working folder is `Voice_Agent` and read the selected level before using them.

## Plan a level

“Load the project roadmap guidance and review this level's entry evidence, current reuse, shared contracts and owner questions. Define one bounded implementation and meaningful tests before code. Preserve Twilio/Pipecat and existing PostgreSQL/Dramatiq foundations; report missing gate evidence honestly.”

## Review conversation or safety

“Load the guardrail guidance. Check deterministic stage/slot authority, readback/commit truth, Indic normalization, blocked claims, prior-quote pressure, RAG evidence boundaries, safe failures and matching fixed audio. No generated speech may bypass final safety.”

## Review concurrency or jobs

“Check per-call isolation, bounded queues, event-loop blocking, cancellation/Twilio clear, late results and shutdown. Distinguish single recording-consumer recovery from row-claimed Dramatiq jobs. Verify exact-payload recording ack, SQL effect/settlement, retry/lease bounds and privacy.”

## Verify a level

“Run the relevant offline/fake-provider checks and separately identify local-lab/live requirements. Record revision/environment/data/configuration, results and limitations in the level brief. Existing source or a regression pass cannot close unmeasured quality/capacity or production controls.”
