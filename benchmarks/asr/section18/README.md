# Section 18 public ASR evidence

Manifest and reports use `google/fleurs`, validation row 0 for `gu_in`, `hi_in` and `en_us`, provided under [CC-BY-4.0](https://huggingface.co/datasets/google/fleurs). Attribution: FLEURS dataset authors/contributors and the Google FLEURS project. Reports contain public reference/hypothesis text, never caller/project recordings or credentials. Derived noise/telephone and stitched language-pair cases are explicitly identified in the manifest.

Raw WAVs and exported failure clips remain ignored runtime artifacts. Reproduce/download public audio and read failures using the [runbook](../../../docs/runbook.md#section-18-asr-benchmark-and-failure-review). The [Level 4 brief](../../../docs/levels/level-04.md#section-18-asr-benchmark) owns interpretation and remaining gates.

The separate [local base report](whisper-base-local-report.json) uses the same 15-case manifest, verified [base artifacts](../whisper-base-artifacts.json) and offline CPU INT8 inference. All requests completed; Gujarati/Hindi/stitched quality failed. Hosted reports remain unchanged. Execution success is distinct from quality approval.

The separate [pinned local Indic report](indic-conformer-local-report.json) accounts for all 15 cases: 12 supported successes and three explicitly unsupported English cases, with no fallback or invented score. The [fresh base report](whisper-base-local-20261021-report.json) completes 15/15 and preserves the old report. The [checked comparison](indic-vs-whisper-base-local.json) pairs the same audio/reference hashes and normalization, compares weighted WER/CER and separates first-process loading from an 11-case shared warm cohort. Shared WER/CER is Indic **33.33% / 23.94%**, base **100% / 96.91%**. Indic remains weak on stitched English spans. All runs are cache-only; no paid LLM, hosted inference, new downloads or microphone tests ran.

The [systematic diagnosis](indic-systematic-diagnosis.json) separates the code-mix language/vocabulary mismatch from model-wrapper/scoring faults. It records 12/12 local–hosted transcript equality, four direct CTC/RNNT/config probes, full encoded audio lengths and six monolingual cases at **15.43% WER / 3.98% CER**. Known-source-boundary recombination is explicitly an oracle-boundary diagnostic, not an implemented language router or a passed voice gate.

The [adaptive local report](adaptive-local-report.json) is the historical, retired `phrase-span-v5` lab. Explicit mixed hints preserve one strong phrase boundary before ASR and route the Indic head to pinned IndicConformer. Whisper inspects candidate English spans without a forced language; only detected, credible English is accepted, otherwise IndicConformer retains the span or the failed candidate remains empty. An exact booking-loanword normalizer handles no-gap turns. All 15 cases execute offline. Clean/telephone stitched cases pool to **12.50% WER / 3.50% CER**; noisy stitched cases are **40.48% / 22.64%**, and mixed median wall time is **2.031 s**. This fixes systematic suffix deletion on the measured clean/telephone samples but fails noisy-code-mix and latency gates. It is not native code-mix approval.

The historical [single-pass report](single-pass-local-report.json) uses `single-pass-loanwords-v1`: one Indic decode plus exact phonetic keyword normalization for Gujarati/Hindi/mixed turns, and Whisper base only for English. The same 15 audio/reference hashes complete offline. Pure Indic stays **15.43% WER / 3.98% CER**. Mixed median drops to **1.148 s**, but stitched mixed quality is **44.84% / 37.02%** because full English suffixes are omitted. Matching text cannot restore those deletions. Its SQL run is `section18-single-pass-local-20261021-v1` (15 samples / 90 aggregate rows); older reports and rows remain immutable. Native loanword audio/slot recall and the complete section 20 gate remain unapproved.

The [four-phrase synthetic loanword probe](loanword-synthetic-report.json) separately tests installed local Indic-TTS → one actual IndicConformer decode → exact normalization. All four Gujarati/Hindi clips yield all 7 expected keyword occurrences; one other Hindi word is misrecognized. It retains raw/normalized text and model/audio identities, with no microphone, network, paid calls, retained audio or native-quality claim. This supports emitted-loanword matching, not recovery of the full English sentences deleted in the public corpus.

The current [Turbo report](whisper-turbo-local-report.json) uses the same 15-case manifest and pinned [MLX 4-bit artifacts](../whisper-turbo-mlx-artifacts.json). English is 0% WER on these three derived clips; Gujarati/Hindi and both mixed groups fail quality. [Decoding probes](turbo-decoding-probes.json) record CPU/MLX memory and token/language/timestamp/prompt trials; the [four-phrase synthetic loanword report](turbo-loanword-synthetic-report.json) is separate from natural speech. The [install/removal record](../whisper-turbo-local-install.json) confirms Turbo retained and Indic weights removed. SQL run `section18-whisper-turbo-local-20261021-v1` stores 15 samples / 90 aggregate rows. Execution success, synthetic keywords and saved SQL do not pass native/production approval. Paid Claude and microphone tests remain deferred.
